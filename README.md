# MyGymBuddy 🏋️‍♂️

Your all-in-one fitness tracking web app – track workouts, meals, progress, stay motivated, share your progess and training plans with your friends and talk to them directly inside the app.  
This is my first major project after learning the fundamentals of web development, therefore the lack of frameworks deepend my knowledge in vanilla JavaScript syntax and usage!

---

## ✨ Features

- ✅ User registration & login
- 🍎 Meal tracking with nutritional info (OpenFoodFacts API and local data for offline use)
- 🏃 Workout planner and logger
- 📊 Weight & progress tracking
- 🤝 Social tab – follow friends, view their activity, chat with them
- 📅 Personalized training schedule
- 🧠 Fun and scientific food facts
- 🛡️ Secure and user-friendly interface

## 🚀 Getting Started

### Prerequisites

Make sure you have these installed:

- [Node.js](https://nodejs.org/)
- [XAMPP](https://www.apachefriends.org/)

### Environment variables for local use

(This is an example)

- DATABASE=useracc
- DATABASE_HOST=localhost
- DATABASE_USER=root
- DATABASE_PASSWORD=
- SESSION_SECRET=Abc123@

### Installation

```bash
git clone https://github.com/Alex110506/mygymbuddy.git
cd mygymbuddy
npm install
npm start

```
